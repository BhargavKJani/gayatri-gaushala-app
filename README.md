# ગાયત્રી ગૌશાળા – એપ (Gayatri Gaushala app)

## 📲 એપ ડાઉનલોડ કરો / Download the app

**[⬇ gayatri-gaushala.apk](https://github.com/BhargavKJani/gayatri-gaushala-app/releases/latest/download/gayatri-gaushala.apk)**

1. Android ફોનમાં ઉપરની લિંક ખોલો અને ફાઇલ ડાઉનલોડ કરો.
2. ડાઉનલોડ થયેલી ફાઇલ ખોલો. પૂછે તો **"Install unknown apps"** ની પરવાનગી આપો.
3. **Install** દબાવો.

Open the link on an Android phone, download the file, open it, allow "Install unknown apps" if asked, and tap **Install**.
